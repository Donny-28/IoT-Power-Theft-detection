# IoT-Power-Theft-detection
An Arduino based IoT system for detecting electricity theft using the Blynk IoT platform

# Components:
1. Arduino Uno
2. Current Sensor (ACS712)
3. Voltage Sensor 
4. Tamper Detection Sensor (Reed Switch)
5. ESP8266 Wi-Fi Module
6. Relay Module: Used to disconnect power supply in case theft is detected. 
7. IoT Platform (Blynk)
8. Buzzer
